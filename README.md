# 坦克大战 · Battle City

一个使用原生 HTML / CSS / JavaScript（Canvas）实现的经典俯视角坦克大战游戏，单文件即可运行，无需任何依赖或构建步骤。

## ✨ 功能特性

- 🎮 键盘操作：`WASD` / 方向键移动，`空格` / `J` 射击，`P` 暂停
- 🧱 多种地形：砖墙（可摧毁）、钢墙、水面、草丛（可隐藏坦克）
- 🏰 基地保护：守住己方基地，一旦被摧毁游戏结束
- 🤖 敌人 AI：随机移动与射击，按波次从顶部刷新
- 💥 粒子特效与程序化音效（Web Audio，无需素材文件）
- 📈 关卡递进：通过后敌人数量与难度提升
- 🖥️ 像素风格渲染，自适应 416×416 画布

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可开始游戏：

```bash
# 方式一：双击 index.html
# 方式二：启动本地静态服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 提示：游戏基于纯前端实现，无需后端或网络请求，也适合部署到 GitHub Pages。

## 🕹️ 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` / `J` | 发射子弹 |
| `P` | 暂停 / 继续 |

## 🧠 技术要点

- 使用 Canvas 2D 渲染地图瓦片、坦克、子弹与粒子
- 26×26 网格瓦片地图，经典 Battle City 布局（对称砖墙 / 钢墙 / 水面 / 草丛）
- 面向对象式实体管理（玩家 / 敌人 / 子弹 / 粒子）
- Web Audio API 生成射击与爆炸音效
